# HeX3, the HeXAI cluster

HeX3 (or hx3) is an AI focused cluster for both teaching a research. It will grow over time but at the moment has:

* 16x Lenovo SD650N-v3 compute nodes with:
    * 2x Intel EMR 6562Y+ CPU’s 
    * 4x NVIDIA H200 141GB GPU’s 
    * 1.5TB Memory 

* 3x Lenovo SD665N-v3 compute nodes 
    * 2x AMD EPYC 9555 64-Core CPU’s 
    * 4x NVIDIA H200 141GB GPU’s 
    * 1.5TB Memory
